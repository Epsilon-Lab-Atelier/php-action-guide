# ネットサービスのリスクチェック

使っているサービスの公式情報から、自分に関係する情報と必要な対応を確認するWebアプリです。情報漏洩・不正アクセスと、PHPの問題を分けて掲載しています。

## 使い方

1. テーマを選び、サービス名・企業名またはURLから探します。
2. 公開されている状況、対象範囲、公式の対応案内を確認します。
3. 自分の利用状況を選ぶと、関係する情報と次に確認することが表示されます。

利用状況は、登録・支払い・本人確認書類の提出・過去の利用など、掲載されている情報の範囲に合わせて選べます。選択の数や利用頻度で危険度を採点せず、個人の被害の有無も判定しません。確認メモの作成・保存や、確認済み項目のチェックはありません。

## 更新履歴

上部の「更新履歴」で、その日にどの企業・サービスの掲載情報が追加・変更されたか確認できます。日付、テーマ、企業名で絞り込み、変更内容と出典を確認して各サービスの案内へ進めます。初めて掲載した記録、続報・訂正、アプリの機能変更を区別しています。

日付はこのアプリの掲載内容を変更した日です。事案の発生日、公式発表日、資料を読んだ日とは異なります。

## 調査と公開への反映

PHP対応は `src/catalog*.mjs`（`catalog-breach.mjs`を除く）、情報漏洩の事案は `src/incidents.mjs` に独立して記録します。PHPに掲載していない企業も `src/catalog-breach.mjs` に追加できます。情報漏洩からPHP利用や原因を推定しません。

外部の定期タスクは日本時間の毎朝8時に調査を予定しています。調査・検証・レビュー用PRの作成までを自動化する設定で、公開サイトに即時・自動反映する設定ではありません。確認日は実際に読めた資料だけ更新します。[定期調査の運用](docs/automatic-updates.md)に詳細を記載しています。

## 情報の扱い

選択内容と入力URLは外部へ送信せず、端末にも保存しません。URL検索は登録済みドメインとの照合です。入力先への接続、PHPの検査、個別の被害確認は行いません。未掲載や未確認を「被害なし」「安全」と判断せず、公式の最新案内を確認してください。

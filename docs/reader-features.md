# 読者向け機能

## サービスを探す

サービス名・企業名の検索と、常に表示される「サービスの種類」のプルダウンを組み合わせて探せます。「すべて」に戻すと種類の絞り込みを解除できます。検索語が別のテーマだけに掲載されたサービスと一致する場合は、そのテーマへの案内を表示します。案内から移動すると検索語を引き継ぎ、種類の絞り込みを解除します。立場が変わる場合は、移動先の立場もボタンに表示します。

「お名前.com デスクトップクラウド」は、「GMO」「GMOインターネット」「GMOインターネットグループ」などの名前でも検索できます。確認できた運営企業名をサービス名と併記し、企業グループ名で調べても対象サービスを見分けられるようにしています。グループ内の全サービスに同じ事案やPHPの問題があると判断するものではありません。

## 公開情報から次の行動へ

サービスを選ぶと、公表内容、対象者、対象期間、公式の対応案内が出ます。利用状況を選ぶと「まずすること」を先頭に表示し、関係する情報と確認事項を続けます。通知が届いた場合は通知の真偽と対象手続き、過去の利用は対象期間、noteの投稿歴は公表された投稿条件を確認します。選択数による危険度や個人の被害判定は行いません。

## ウォッチリスト

案内の「＋ ウォッチリスト」で企業・サービスを追加し、上部の「ウォッチリスト」から開きます。情報漏洩・不正アクセスとPHPの状況、公式資料の確認日時、掲載情報の変更をまとめて確認できます。会社の全サービス・全利用者を対象と推測しません。

保存するのは企業・サービスIDと、情報漏洩/PHPそれぞれで前回開いた内容の識別情報です。利用状況、入力URL、名前、メールアドレス、パスワードは保存・送信しません。他の端末やブラウザとの同期はありません。

追加時点の過去の履歴は新しい変更として扱いません。その後に掲載内容が変わった場合は「前回見た後に掲載変更」と表示します。リストを開くだけで変更表示は消しません。案内を開いたテーマの目印だけを更新し、もう一方のテーマは維持します。資料の確認日時だけの変更は新しい掲載変更として数えません。過去事案を新規掲載した場合は掲載変更になりますが、最近発生した事故を意味しません。

各カードの「解除」で外せます。保存領域は `epsilon-risk-check.watchlist.v1` のみを使い、旧版のメモ・保存サービス領域は読みません。保存を拒否された場合や容量不足でもページを開いている間は利用できます。壊れたデータは起動時に勝手に書き換えず、新しい追加操作で有効な保存内容を作ります。

## 更新履歴と日時

日付・テーマ・企業名で絞り込めます。件数のすぐ近くに、アプリへの追加・変更であり過去の事案も含むことを明記します。対象範囲の拡大、必要な対応の変更、対応変更なしは、公式本文と以前の案内を比較した記録がある場合に表示します。未分類の古い履歴から「変更なし」と推測しません。

公式情報の確認日時は参照資料の最も古い成功確認を用います。資料が取得できなかったときも前回成功日時を保持し、失敗した資料を出典に示します。記録が日付のみなら「時刻未記録」とします。朝6時・夕18時は調査開始の目安で、公開完了時刻ではありません。

## 情報の扱い

利用状況の回答はページを開いている間だけ保持します。確認メモ、完了チェック、印刷・コピーの専用機能はありません。URLは登録ドメインと照合し、入力先へアクセスせず、危険性の検査もしません。

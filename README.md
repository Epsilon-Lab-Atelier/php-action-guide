# PHP Action Guide

EpsilonLabによる、PHPの問題について公式情報と確認事項を整理する日本語Webアプリです。サービス利用者とCMS・サーバー管理者を分け、PHP利用・対象の問題への説明・必要な行動を区別して案内します。

## 使う

`dist/index.html` をブラウザで開いてください。HTMLにCSS、JavaScript、登録情報を含むため、サーバーの起動やインストールは不要です。公式資料への移動にはインターネット接続が必要です。

- 一覧からサービス・CMSを選ぶか、URLを入力します。
- URLは登録ドメインとだけ照合します。URL先への通信、DNS照会、PHPの検査は行いません。
- 独自ドメインなどで一致しなければ、利用先を確認して一覧から選んでください。
- 未確認の内容から、安全・対応不要・PHP不使用とは判断しません。

初版の掲載対象はnote、WordPress.com、pixiv、BOOTH、自分で設置したWordPress、Drupalです。情報確認日は2026-10-24です。特定のサービスについて、同じ会社の別サービスまで対応状況を推測しません。

## 開発

Node.js 22以上を使用します。外部パッケージのインストールは不要です。

```sh
npm run build
npm test
```

ビルド後の `dist/index.html` は単一ファイルです。相対パスに依存する外部アセットがないため、GitHub Pagesのプロジェクトサブパスでも使えます。

| ファイル | 用途 |
| --- | --- |
| `src/catalog.mjs` | サービス情報・根拠URL・確認日・ドメイン登録 |
| `src/url.mjs` | URL正規化・ドメイン境界の照合 |
| `src/app.mjs` | 表示・操作・確認チェック |
| `src/index.html` | 画面構造と対象の問題の説明 |
| `src/style.css` | レスポンシブ表示 |
| `scripts/build.mjs` | 単一HTMLの生成とCSPハッシュ生成 |
| `tests/` | URL・データ・配布HTMLの検証 |
| `docs/` | 設計・情報更新・検証の記録 |

## 情報を更新する

公式の一次情報を読み、`src/catalog.mjs` の該当する事実・出典・確認日を更新します。全体の確認日を更新するときは `src/index.html` にある日付と対象問題の説明も見直します。`npm run build` と `npm test` を実行し、ブラウザで表示を確認してください。

日付だけを新しくせず、実際に確認した資料の範囲を記録してください。古い告知から、新しい脆弱性への対応済みとは推測しません。確認日から7日以上が経過すると、公式情報の再確認を促す表示が出ます。

## GitHub Pagesへの準備

公開時は、承認したコミットの `dist/` の内容をPagesの配信ルートへ置きます。ブランチ配信を使う場合は、配信用ブランチのルートへ `index.html` と `.nojekyll` を配置できます。これは公開作業の説明であり、このソース一式に自動デプロイする設定やActionsは含まれていません。

現時点で公開サイトは提供していません。GitHub Pagesの公開範囲や設定の変更は、公開時に別途行ってください。

## 制約

登録情報は手作業で確認した時点の記録です。最新情報の自動取得、任意サイトのPHP検査、被害判定、脆弱性スキャン、リアルタイムの稼働監視はありません。個別サイトや未登録ドメインの状態は判定できません。

入力やチェック状態をアプリ側で保存・外部送信しません。ブラウザの復元機能などで画面が残る場合があります。公式リンクは新しいタブで開き、参照元を送らない設定にしています。

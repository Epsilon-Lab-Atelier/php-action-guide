# 掲載サービスの分類監査 — 2026-10-28

EpsilonLabの掲載サービス全165件について、読者がサービスの種類から探せるよう、分野・用途と分類の対応を点検した記録です。分類データの比較基準は、検証済みの [main 6cfcb88](https://github.com/Epsilon-Lab-Atelier/php-action-guide/commit/6cfcb88) です。下表には、今回の見直し後の分類を掲載しています。

分類は案内のための情報です。分類の追加・変更によって、情報流出の対象サービス・対象者・対象期間を広げることはありません。また、分類監査日を公式資料の確認日に置き換えません。今回の変更では、事案本文・出典・公式情報の確認日時を保持しています。

## 分類の基準

- 主分類は、掲載しているサービス・組織の実際の分野や用途で決めます。委託先の種類、侵入経路、使用システムだけでは分類を決めません。大阪大学は、委託先クラウドに関する事案でも「教育・研究」です。
- 複数の分野・用途から探す理由があるサービスには、副分類を付けます。「すべて」では主分類に一度だけ表示し、種類を選ぶと主分類・副分類の両方を検索対象にします。
- 名前が似ていてもサービスの範囲を区別します。三菱ガス化学は家庭向けガスサービスに分類せず、ヤマハ（YNE）は掲載対象のネットワークエンジニア会に合わせて分類します。
- 学校法人の出版部、医療機関向け業務サービス、FX用途のクラウドなどは、必要な入口を副分類で補います。お名前.comの金融からの案内はFX用途によるもので、GMOの他サービスに事案を広げる意味ではありません。
- 利用者と運営者の分類を分けます。各対象の立場に主分類を明示し、未設定の分類を自動的に「仕事・採用・法人向け」で補いません。

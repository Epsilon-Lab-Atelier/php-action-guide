# ネットサービスの確認手帳

PHPの問題や情報流出・不正アクセスについて、利用しているサービスの公式情報と、自分に必要な確認事項を整理できるWebアプリです。

## できること

- サービスごとの公式案内と、その出典・確認日を確認する
- 利用者・サイト管理者の立場や、サービスの使い方に合った確認事項を整理する
- 確認済みの項目にチェックを付け、メモをコピー・保存・印刷する
- ページを開いている間は、サービスごとに確認の続きへ戻る
- サービス別の案内リンクを共有し、希望するサービスだけ端末に覚えさせる

## 使い方

1. 「情報漏洩・不正アクセス」か「PHPの問題」を選びます。
2. 立場を選び、サービス名またはURLから探します。
3. 最初に表示される対象範囲と、公式の対応案内を確認します。
4. 必要に応じて詳細や確認メモを開きます。

確認できた項目にはチェックを付けられます。後から見返したい内容は、確認メモとして手元に残せます。

## 調査と公開への反映

PHP対応は `src/catalog*.mjs`（`catalog-breach.mjs`を除く）、情報漏洩の事案は `src/incidents.mjs` に独立して記録します。PHPに掲載していない企業も `src/catalog-breach.mjs` に追加できます。共通の検索用ディレクトリは両者を結びますが、情報漏洩からPHP利用や原因を推定しません。

外部の定期タスクは日本時間の毎朝8時に調査を予定しています。調査・検証・レビュー用PRの作成までを自動化する設定で、公開サイトに即時・自動反映する設定ではありません。確認日は実際に読めた資料だけ更新します。詳しくは [定期調査の運用](docs/automatic-updates.md) を参照してください。

## ご利用にあたって

URL入力は、登録済みサービスとの照合に使います。入力先のサイトに接続して、PHPの使用状況や被害の有無を検査する機能はありません。掲載情報やチェックの完了だけで安全とは判断せず、サービス提供元の最新の公式案内をご確認ください。

入力内容やチェック状況を、アプリ側で外部送信・端末へ自動保存することはありません。サービスと立場ごとの確認途中のメモは、ページを開いている間だけ保持します。必要な内容は、確認メモとして保存してください。

「このサービスを端末に覚えておく」を押した場合だけ、サービス・立場と掲載内容の変更を確かめる目印を端末に保存します。チェック・利用状況・入力URLは保存しません。保存一覧はいつでも削除できます。
